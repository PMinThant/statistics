# Health and Sleep Quality Analysis

Descriptive statistical analysis of health and lifestyle factors affecting sleep quality using Python.

## Project Overview

This project explores a health and lifestyle dataset to understand patterns in sleep quality and related health metrics. Using descriptive statistics, the analysis identifies key trends, outliers, and relationships between variables such as sleep duration, physical activity, stress levels, and overall health indicators.

**Completion Date:** May 2026

## Dataset

- **Source:** Udacity Sleep Health and Lifestyle Dataset
- **Format:** CSV file with health metrics and lifestyle factors
- **Key Variables:** 
  - Sleep duration
  - Quality of sleep
  - Physical activity level
  - Stress level
  - BMI category
  - Blood pressure
  - Heart rate
  - Daily steps

## Tools & Technologies

- **Analysis Software:** Google Sheets / Excel for initial exploration
- **Presentation:** Google Slides / PowerPoint
